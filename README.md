# 🖥 GUI-Based Python Projects

## 📌 Repository Overview

This repository contains two desktop applications developed using **Python** and **Tkinter**. Both projects demonstrate Object-Oriented Programming principles, GUI development, exception handling, and practical problem-solving using Python.

---

# Projects Included

## 🏦 1. Bank Account Management System

A GUI application for basic banking operations.

### Features

- Savings Account
- Checking Account
- Deposit
- Withdraw
- Balance Inquiry
- Exception Handling
- OOP Implementation

---

## 📚 2. Library Management System

A GUI application for managing books and members.

### Features

- Book Management
- Member Management
- Borrow Books
- Return Books
- Transaction History
- JSON File Storage
- Data Persistence

---

# Installation

Clone the repository.

```bash
git clone https://github.com/username/Python-GUI-Projects.git
```

Navigate to the project folder.

```bash
cd Python-GUI-Projects
```

---

# Running the Projects

## Bank Account Management

```bash
cd BankAccountManagement
python bank.py
```

---

## Library Management

```bash
cd LibraryManagement
python library.py
```
